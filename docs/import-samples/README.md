# Import samples

Files to try the "Import file" button on the dashboard.

- `meeting-notes.md`: headings, bold, italic, lists, a quote and a third-level heading (demoted to H2 on import).
- `release-note.txt`: plain text, blank lines become paragraphs.
- `word-draft.docx`: a real Word file with headings and lists.
- `corrupt.docx`: not a real Word file, shows the "could not read that file" error.

Limit: 2MB. Accepted: `.txt`, `.md`, `.docx`.
